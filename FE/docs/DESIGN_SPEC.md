# UMI Studio 프론트엔드 UI/UX 명세

## 1. 목적과 기준

현재 구현된 화면의 정보 구조, 상호작용, 시각 규칙을 정의합니다. 구현 기준은 `app/`(라우트), `components/views/`(화면), `app/globals.css`(스타일), `public/`(이미지)입니다. 화면 데이터는 백엔드 REST API에서 오며, 관리자 화면과 회원가입 모달만 UI 목업입니다.

## 2. 정보 구조

```text
/                 랜딩·로그인·튜토리얼
/dashboard        대시보드
/data             데이터(Episode)
/skills           동작 목록
/learning         학습 목록
/learning/new     학습 생성
/work             작업 목록
/work/new         작업 생성
/work/:id/edit    작업 편집
/devices          장치 관리(UMI·로봇 탭, ?tab=)
/devices/:robotId 로봇 상세
/admin            관리자(사이드바 미노출, URL 직접 진입)
```

- 학습: 동작 선택 → 데이터 방식(새 수집/기존 Episode) → 데이터 선택 → 최종 확인 → 생성 → 학습 목록에서 진행 확인
- 작업: 목록 검색 또는 작업 추가 → 블록 구성 → 저장 → 실행 준비(로봇 선택·배포) → 실행·중지
- 장치: UMI/로봇 탭 → 최근 사용순 확인 → 장치 추가(로봇 직접 등록, UMI QR 등록) 또는 로봇 상세

화면 전환은 Next.js App Router 라우팅입니다. 뒤로 가기·새로고침·딥링크가 동작하며, 로그인이 필요한 구간은 `app/(console)/layout.tsx`가 랜딩으로 되돌립니다.

## 3. 내비게이션

### 데스크톱(901px 이상)

- 왼쪽 고정 남색 사이드바(244px). 로고 → 랜딩.
- 메뉴 순서: `대시 보드`, `데이터`, `동작 목록`, `학습`, `작업`, `장치 관리`. 하위 메뉴는 없고 각 메뉴는 목록 화면으로 이동합니다.
- 현재 메뉴는 배경·텍스트 대비로 표시하며, 생성·상세 화면에서도 상위 메뉴가 활성 상태를 유지합니다(`/learning/new` → 학습).
- 하단에 인사말과 `SIGN OUT`.

### 모바일(900px 이하)

- 상단 바 + 햄버거 버튼, 오버레이 메뉴. 메뉴 항목 아래 로그인/로그아웃.
- 메뉴가 열리면 배경 백드롭을 눌러 닫을 수 있습니다.

## 4. 화면별 명세

### 랜딩·인증

- 실버 UMI Studio 로고와 한 줄 메시지, 로그인 버튼, 튜토리얼(가이드 포인트 2개).
- 로그인·회원가입은 중앙 모달. 이메일·비밀번호(데모 계정 기본 입력), 비밀번호 표시 전환, 오류 문구, Escape 닫기.
- 로그인 성공 시 `/dashboard`(또는 진입 시 요청한 화면)로 이동. 세션이 살아 있으면 랜딩에서 대시보드로 자동 이동합니다.
- 회원가입 모달은 검증 후 입력값을 로그인 폼에 채우는 UI 목업입니다.

### 대시보드

- 상단 4개 요약 카드: 등록된 UMI, 등록된 로봇, 진행 중인 학습, 오늘 완료한 작업. 카드는 해당 탭/목록으로 이동합니다.
- `현재 실행 중인 작업` 카드: 로봇 필터, 5초 폴링, 헤딩에 `N개 실행 중` 배지. 카드 높이는 약 4행(280px)으로 고정하고 내부 스크롤합니다.
- 하단 2열: 로봇 상태, 최근 학습.

### 데이터

- 제목 우측에 상태 필터(전체·학습 가능·처리 중·확인 실패)와 정렬(최신·오래된 등록순·보관 만료 임박순).
- 표 행의 데이터명을 누르면 상세 모달(정보 격자 + 미리보기 + 조건부 행동).
- 상태 표시는 점 + 텍스트 + 저채도 배경 배지입니다.

### 동작 목록

- 제목 우측 `동작 추가`. 아래 검색창(동작 이름·설명 부분일치).
- 표 열: 동작 이름, 설명, 최신 버전, 버전 생성 시각, 배포 상태, 최근 학습 요청.
- 동작 이름을 누르면 설명 수정 모달. 12개 단위 페이지네이션.

### 학습 목록

- 제목 우측 `학습 추가`(→ `/learning/new`).
- 상태 요약 영역(전체·진행 중·완료·확인 필요)이 필터를 겸합니다.
- 목록 제어: 좌측 `마지막 갱신` 문구, 우측 `삭제`(선택 모드 전환) · `새로고침` · 상태 드롭다운.
- 행: 학습명(누르면 상세), 로봇·시작 시각, 현재 단계, 진행률 막대+숫자, 상태 배지. 12개 단위 페이지네이션.
- 상세 모달에서 상태에 따라 `이 동작으로 작업 생성`, `학습 취소`, `다시 시도` 중 하나를 제공합니다. 취소·삭제는 확인 모달을 거칩니다.

### 학습 생성

- 단계 표시줄 아래 한 장의 카드로 진행합니다. 완료 단계는 저채도 녹색, 현재 단계는 저채도 남색.
- 새 수집(UMI 선택·예상 Episode 수) 또는 기존 Episode 선택(학습 가능 항목만 선택 가능).
- 진행 중 초안은 `localStorage`에 보존되어 새로고침 후 이어집니다.
- 최소 Episode 수 강제는 BE 정책 확정 전까지 하지 않습니다.

### 작업 목록

- 제목 우측 `작업 추가`. 그 아래 `현재 실행 중인 작업` 카드(대시보드와 동일 컴포넌트).
- 검색창(작업명·포함 블록)과 `삭제`(선택 모드)가 카드 없이 페이지 위에 놓입니다.
- 목록 카드: 작업 / 예상 시간 / 최근 수정일 열, 헤더 우측 `전체 N개`. 커서를 올린 행만 강조하고 기본 선택은 없습니다. 12개 단위 페이지네이션.
- 행을 누르면 우측(모바일은 전체 화면) 상세, 상세에서 편집·실행 준비로 이동합니다.

### 작업 생성·편집

- 3단계: `작업 구성` → `실행 준비` → `실행`.
- 블록 팔레트: 학습 동작(서버 스킬 목록) + 모터 움직이기 + 반복하기. 클릭 또는 드래그로 추가, 순서 변경·삭제.
- 모터 각도 범위(`lib/blocks.ts`의 관절별 범위), 반복 횟수·내부 블록을 저장 전에 검증합니다.
- 실행 준비에서 로봇을 선택하면 준비 상태를 확인하고 배포를 만들며, 실행 화면에서 진행률과 중지를 제공합니다.

### 장치 관리·로봇 상세

- 제목 우측 `장치 추가`(공통 생성 버튼). 탭 `UMI N` / `로봇 N`, 툴바에 `삭제`(선택 모드)와 정렬(최근 사용순·오래된 순).
- 장치 카드: 시각 표식, 상태 배지, 이름, 위치, 정보 2행. 로봇 카드는 상세로 이동.
- 등록 모달: 로봇은 이름·ID·위치 입력, UMI는 QR 코드를 장치가 스캔하면 2초 폴링으로 완료를 감지합니다.
- 로봇 상세: 상태·현재 모델, 최근 작업 기록, 로봇 설정(이름·위치 수정). 모델 설치·교체 UI는 노출하지 않습니다.

### 관리자(목업)

- 사용자 목록 → 접근 가능 로봇 체크 → 저장(토스트만). 데이터는 `mocks/users.ts`.

### 타이포그래피

SUIT Variable(jsDelivr 로드) → Noto Sans KR → Malgun Gothic. 본문 400, 제목 650, 버튼 600~700, 행간 1.5, 숫자 tabular.

| 요소 | 크기/굵기 |
|---|---|
| 페이지 제목 h1 | 32px / 650 (680px 이하 26px) |
| 카드 제목 h2 | 18~19px / 600 |
| 목록 항목 제목 | 15px / 600 |
| 본문·입력·버튼 | 14px |
| 메타(보조 문구, 컬럼 헤더, 날짜) | 13px |
| 상태 배지 | 12px / 600 |
| 안내문(빈 상태 등) | 14px, 제목 아래 설명 15px |

10~12px 텍스트는 사용하지 않습니다(목록 화면 기준 2026-09 정리).

### 공통 컴포넌트

- **페이지 헤딩**: h1 좌측, 우측에 생성 버튼 하나. `align-items:center`, 아래 1px 구분선.
- **생성 버튼**(`.primary-button.page-create-button`): 채운 남색 그라데이션, 44px 높이, 15px/700, 라벨은 `{대상} 추가`(동작·학습·작업·장치)로 통일. chevron·아웃라인 스타일은 사용하지 않습니다.
- **주 버튼** `.primary-button`: 남색 채움, 9px 라운드, 14px/650. **보조 버튼** `.secondary-button`: 흰 배경 + 강한 라인. **위험 버튼** `.danger-button`: 삭제·취소 확정.
- **툴바 컨트롤**(select·새로고침·삭제·검색 입력): 38px 높이로 통일.
- **검색창** `.workflow-search`: 좌측 ⌕ 아이콘, 최대 430px. 작업 목록과 동작 목록이 같은 마크업을 씁니다.
- **페이지네이션** `.pagination`: 이전 / 번호(현재는 주 버튼) / 다음, 12개 단위, 1페이지면 숨김.
- **상태 배지**: 점 + 텍스트 + 저채도 배경. 학습 배지는 `complete`/`failed` 변형.
- **진행률**: 막대·숫자·배지를 고정 열에 배치하고 넘치지 않습니다.
- **모달** `.modal-backdrop` + 카드: 뷰포트 기준 정중앙 `position:fixed`, 열리는 동안 문서 스크롤 잠금(콘솔 레이아웃이 일괄 처리). 제목/닫기 → 본문 → 조건부 행동 영역.
- **확인 모달** `.confirm-modal`: 파괴적 행동(삭제·취소) 앞에 반드시 사용.
- **선택 모드**: `삭제` 버튼을 누르면 체크박스가 나타나고 버튼이 위험 버튼으로 바뀝니다. 다시 누르면 선택 항목 삭제 확인 또는 모드 해제.
- **토스트**: 우측 하단, 결과 한 줄.
- **로딩·오류 게이트**: 콘솔 초기 데이터 로드 중 스피너, 실패 시 재시도 카드.

### 시각 방향

- 남색은 구조와 행동, 실버는 로고·반사 표현에만.
- 강한 원색과 다색 AI 그라데이션은 피합니다. 콘솔 배경은 단색 밝은 캔버스, 카드는 얇은 라인과 부드러운 그림자.
- 페이지 진입은 opacity만 짧게 전환합니다(transform 애니메이션은 `position:fixed` 모달 위치를 깨뜨려 사용하지 않음).

## 6. 반응형

| 구간 | 변화 |
|---|---|
| 1281px 이상 | 콘텐츠 최대 폭 1280px 중앙 정렬 |
| 1180px 이하 | 작업 목록 2열 → 1열, 대시보드 2열 → 1열 |
| 1100px 이하 | 요약·장치 카드 4열 → 2열 |
| 900px 이하 | 사이드바 → 상단 바 + 오버레이 메뉴, 여백 축소, 표 컬럼 헤더 숨김 |
| 680px 이하 | 제목 26px, 헤딩·툴바 세로 배치, 생성 버튼 우측 정렬 |
| 560px 이하 | 툴바 2열 그리드, 카드 최소 높이 해제 |

긴 텍스트·진행률·배지는 수평 스크롤 없이 표시해야 합니다. `prefers-reduced-motion`에서는 전환을 끕니다.

## 7. 접근성과 사용성

- 입력은 보이는 라벨, 아이콘 버튼은 `aria-label`.
- 상태는 색상 + 텍스트 + 점으로 전달.
- 모달은 `role="dialog"`, `aria-modal`, 백드롭 클릭 닫기(진행 중에는 잠금).
- 페이지네이션 현재 페이지는 `aria-current="page"`.
- 드래그 가능한 블록은 클릭으로도 추가.
- 실패·비활성 상태에는 다음 행동(다시 시도, 전체 상태 보기 등)을 함께 표시.

## 8. 알려진 제약과 후속 작업

- 동작·작업 삭제 UI는 BE 삭제 API 이후 추가(학습·장치는 선택 삭제 제공).
- 페이지네이션은 전체 번호를 렌더합니다. 수십 페이지가 되면 윈도잉으로 교체.
- 학습 생성·작업 편집 위저드와 모달 내부 타이포는 목록 화면 기준(§5)으로 아직 통일하지 않았습니다.
- 랜딩·튜토리얼 스타일은 콘솔과 별도 규칙(대형 타이포, 이미지 배경)을 유지합니다.
- 액세스 토큰이 `localStorage`에 있어 XSS 노출 가능성이 있습니다(README 참고).

## 9. 완료 기준

- 모든 라우트가 새로고침·뒤로 가기·딥링크로 접근 가능하고, 비로그인 진입은 랜딩으로 돌아갑니다.
- 목록 화면 4곳의 제목·생성 버튼·툴바 컨트롤 크기가 §5 수치와 일치합니다.
- 모달은 긴 페이지에서도 뷰포트 중앙에 뜨고 배경이 스크롤되지 않습니다.
- 카드·표·진행 상태가 화면 밖으로 넘치지 않습니다.
- `pnpm lint` 오류 0, `pnpm build` 통과.
- 목업 범위(관리자·회원가입·미리보기)는 문서와 코드 주석에서 구분합니다.
