# 프론트엔드 문서

공개한 프론트엔드 구현의 화면 설계 문서입니다.

| 문서 | 내용 |
|---|---|
| [UI·UX 명세](DESIGN_SPEC.md) | 화면 구조, 상호작용, 디자인 토큰, 반응형·접근성 기준 |

프로젝트 개요와 빠른 실행 방법은 상위 [README](../README.md)를 확인하세요.

## 관리 원칙

- 화면 동작이나 디자인 규칙이 바뀌면 관련 문서도 갱신합니다.
- 실행에 필요한 설정 파일은 `FE/` 루트에, 설명 문서는 이 폴더에 둡니다.
- 빌드 결과와 로컬 캐시는 문서나 소스 폴더에 추가하지 않습니다.
- 확정되지 않은 API 동작은 실제 기능처럼 기록하지 않고 Mock 또는 예정 상태를 명시합니다.
